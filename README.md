# dwg-lens

**在动手写 DWG 查看器之前，先搞清楚你会丢什么。**

`dwg-lens` 是一个零依赖的 DWG 体检工具。它不渲染、不解压、不当查看器——只回答一个问题：

> 这张图纸，我的解析器能不能读对？读不对会丢哪一块？

## 为什么需要它

自己实现 DWG 查看器（或评估 LibreDWG / 商业 SDK）时，最容易踩的坑是：**代码跑通了，图却不对**。原因通常不是解析器写得差，而是图纸里有一堆你的代码根本不认识的东西——厂商私有对象、缺字体、外部参照。

这些信息在动手之前就能查出来，而且决定了你的架构选型：

- 有厂商自定义对象 → 别指望端上全解析，走服务端或买 SDK
- 大量 SHX 大字体 → 乱码是第一印象问题，得单独排期
- 有外部参照 → 单文件读对了也没用，图是残的

`dwg-lens` 把这三件事一次性列出来。

## 用法

零依赖，只用 Python 标准库（3.9+）。

```bash
# 单张体检
python -m dwglens drawing.dwg

# 出 HTML 报告
python -m dwglens drawing.dwg --html report.html

# 喂给脚本
python -m dwglens drawing.dwg --json

# 批量扫一个目录，出 Markdown 表
python -m dwglens ./drawings --scan

# 接 CI：出现高风险图纸就返回退出码 2
python -m dwglens ./drawings --scan --fail-on-high
```

装成命令（可选）：

```bash
pipx install .
dwg-lens drawing.dwg
```

## 风险等级怎么读

| 等级 | 含义 | 建议 |
|---|---|---|
| **高** | 检出厂商自定义对象（天正/鸿业/探索者/理正…） | 端上全解析不可行。这批图必须走服务端渲染或商业 SDK |
| **中** | 版本 ≥ R2004（数据段压缩），但无自定义对象 | 用 LibreDWG/ODA 完整解析通常可读对；纯字节扫描只能看到部分文字 |
| **低** | 未检出自定义对象，且为早期未压缩版本 | 基础实体可直接读取，自研成本最低 |

## 它不做什么

诚实说明边界，避免误用：

- **不解压**。R2004+ 的图面数据段是 LZ77 变体压缩，本工具只做字节扫描，能看到的文字是压缩流里"恰好以字面量存放"的那部分。**文字抽样是抽样，不是全集。**
- **不渲染**。要出图请用 LibreDWG 的 `dwg2SVG`。
- **不解析实体**。没有实体计数、图层列表、块统计。
- **厂商签名是启发式的**。签名表宁可漏报也不误报（短签名会被随机字节命中），但**漏报可能发生**——命中只说明"大概率有"，未命中不等于"一定没有"。

## 扩展

所有规则都在 `dwglens/vendors.py`，改表即可，不用碰探测逻辑：

- `VERSIONS` —— 版本头映射
- `VENDORS` —— 厂商签名（**新增签名请勿短于 5 字节**，否则误报）
- `TITLE_FIELDS` —— 图签字段
- `DOMAIN_KEYWORDS` —— 工程用词，用来滤掉压缩噪音
